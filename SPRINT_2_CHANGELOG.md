# Sprint 2 — Assets Module

## Added

- Live asset search
- Project and status filters
- Add asset modal
- Edit asset modal
- Asset details modal
- Delete confirmation dialog
- GPS and operational status badges
- Asset summary cards
- Browser persistence using localStorage
- Procore-inspired sidebar, top bar, dashboard, and assets layout
- Placeholder routes for upcoming modules

## Testing checklist

1. Run `npm install` inside `frontend`.
2. Run `npm run dev`.
3. Open the Assets page.
4. Search for `fork` and verify only the forklift appears.
5. Filter by project and status.
6. Add a new asset.
7. Edit the new asset.
8. Open its details.
9. Delete it and confirm the warning dialog.
10. Refresh the browser and verify saved assets remain.
