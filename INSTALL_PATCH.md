# Install the IronTrace Sprint 2 patch

1. Back up or commit your current project.
2. Copy the contents of this patch folder into the root of your existing `IronTrace` project.
3. Allow the matching files to be replaced.
4. In Terminal, run:

```bash
cd frontend
npm install
npm run dev
```

5. Test Dashboard and Assets.
6. Commit the update:

```bash
cd ..
git add .
git commit -m "Build professional assets module with search and editing"
git push
```
